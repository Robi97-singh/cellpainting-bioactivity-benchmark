# Explainability on the 65 random targets (ResNet-50, 448 px)

Model: ResNet-50, 5 input channels, 448 px, one checkpoint per Butina fold (`bioact_resnet_r448_fold0..5`), 29 assays.
Targets: 65 random compound-assay pairs (`random_pos` = known active, `random_neg` = known inactive), the same list as the 224-px run.
Channel order (from the authors' image preparation): DNA, AGP, ER, Mito, RNA.

## What each method shows
- **Grad-CAM** (last conv block, one assay logit): ONE heatmap from all five stains together. The first conv layer mixes the channels, so a per-stain Grad-CAM is not possible.
- **Stain removal**: one stain is replaced by its median, the model is re-run; reported as the change in the assay logit and the change in the Grad-CAM map.
- **Gradient x input**: one map per stain (|gradient x pixel value|), plus each stain's share of the total. A local sensitivity measure, not proof that those pixels cause the prediction.
- No pseudo-RGB is used anywhere in these figures; the five stains are shown in grey.

## Files
- `ablation_resnet448.csv`: per target and variant: logit, score change, map correlation, top-3% overlap.
- `gradxinput_resnet448.csv`: per target: share of |gradient x input| per stain.
- `channel_correlation.txt`: pixel correlation between stains (images and gradient x input maps).
- `figures/`: six example figures, chosen by a fixed rule (see `selected_figures.csv`): for known actives and known inactives separately, the target with the smallest, the median and the largest stain-removal effect. The full set of 65 stays on the cluster and is regenerated by `five_channel_attr_figs.py`.
- `control/`: fluorescence-trained model run on brightfield (see below).

## Findings and limits
- Mean score change when one stain is removed (known actives / known inactives): AGP -0.29 / -0.05, DNA +0.09 / +0.10, ER -0.02 / +0.19, Mito +0.21 / +0.24, RNA -0.41 / -0.30. Effects are modest (at most about 0.4 logits on average); standard deviations across targets are not reported here.
- Share of gradient x input per stain (mean of 65): AGP 25%, Mito 24%, RNA 22%, ER 18%, DNA 11%. Gradient x input scales with pixel brightness, and the DNA channel is mostly dark, so a lower DNA share is expected.
- AGP, ER and Mito are almost copies of each other in the images (pixel correlation 0.96-0.98, RNA 0.85-0.87, DNA 0.5-0.7). Single-stain removal and per-stain results for AGP, ER and Mito should therefore be read as a group, not individually.
- Grad-CAM and gradient x input do not always agree: Grad-CAM can be strongest near the image border, gradient x input on cells and nuclei.

## Control: fluorescence-trained model on brightfield (inference only, no retraining)
The brightfield image is copied into all five channels and fed to the fluorescence-trained 102-plate ResNet-50 (same six folds).

| Condition | Mean AUC |
|---|---|
| Fluorescence-trained, fluorescence images | 0.710 |
| Brightfield-trained, brightfield images | 0.694 |
| Fluorescence-trained on brightfield (fluorescence normalisation) | 0.540 |
| Fluorescence-trained on brightfield (brightfield normalisation) | 0.524 |

The two normalisation variants differ by less than the spread across folds. The two reference rows come from the training code's own scoring, the two control rows from `cv_rescore.py`; differences of a few hundredths between those groups are not meaningful, the gap to about 0.5 is.


ablation_resnet224.csv: the same per-stain ablation for the 224 px ResNet-50 (same columns as ablation_resnet448.csv).
