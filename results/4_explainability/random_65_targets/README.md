# Random 65 targets

The 65 randomly sampled (compound, assay) targets used in all explainability experiments, and the tables computed on them
(`agg_r65.csv`, `bootstrap_ci.csv`, `enrich_r65.csv`, `enrichment_per_target.csv`, `enrich_resnet_per_target.csv`).
`targets_random65.csv` is the list of targets (also in `data_lists/`).

`contact_sheets/` holds the numbered image sheets (made with `explainability/contact_sheet.py`) that were used to label each
target image by eye as normal, sparse or noise; `targets_index.csv` is the index of the targets on the sheets.
